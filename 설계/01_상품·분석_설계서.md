# 상품·분석 설계서 — 공백상권 분석

작성 기준일: 2026-09-30 · 상품 가격: **79,000원 단일 상품**

## 1. 상품 정의

**공공데이터 기반 247개 업종 공백상권 분석**

고객이 입력한 주소 한 곳을 기준으로 공공데이터의 업종 소분류 전체를 조회한다. 모든 검증된 업종을 대상으로 전체 TOP20을 뽑고, 사전에 A 태그로 고정한 생활·방문형 업종만 별도로 모아 A TOP10을 제공한다. 각 결과에 1km·2km·3km·4km·5km 누적 점포 수를 함께 보여준다.

이 상품은 공백·희소 현황을 보여주는 자료다. 특정 업종을 권하거나, 수요·매출·수익성·창업 성공 여부를 예측하지 않는다.

**출시 전 조건:** 2026-06-30 공식 전국 CSV 기준으로 코드·명칭·대/중/소분류 및 247개 업종의 실제 관측 여부를 검증했다. 운영자는 결과를 확인하기 전에 경계 29개를 13개 승인·16개 수정으로 결정했다. 최종 분류는 A 122개, B 39개, C 86개이며, 분류표 버전은 `semas-20260630-taxonomy-v3-abc-6048205a8203`으로 고정했다. 최신 스냅샷으로 갱신할 때는 같은 데이터 검증을 다시 수행한다.

## 2. 고객이 받는 결과

한 분석 주소에 대해 다음 결과를 제공한다.

1. 분석 기준 주소와 좌표 변환 결과.
2. 데이터 출처, 원자료 기준일, 조회일, 업종 분류표 버전 및 수집 완료 상태.
3. 전체 검증 업종에서 뽑은 공백·희소 TOP20.
4. 고정된 A 태그 업종에서 별도로 뽑은 생활·방문형 공백·희소 TOP10.
5. 두 목록 각 업종의 공식 코드·업종명·A/B/C 참고 태그.
6. 각 업종별 누적 반경 점포 수: 1km, 2km, 3km, 4km, 5km.
7. 분석번호, 자료 기준일, 분류표·분석엔진 버전, 수집 완료 상태 및 데이터 한계 고지.

고객 납품물은 PDF 요약본과 247개 업종 전체 누적 점포 수를 담은 XLSX 상세표다. 검토용 HTML은 내부 확인에만 사용하며 납품하지 않는다. `scripts/build_deliverables.py`는 발행 게이트, taxonomy 일치, 247개 코드, 두 순위, 누적 count를 확인한 뒤 PDF와 XLSX를 생성한다. 현재 샘플은 실제 주소·좌표를 비식별 처리한 검토용 결과이며, 실제 주문 주소로 생성·전달하는 절차는 주문 리허설에서 확인해야 한다.

## 3. TOP20 계산과 정렬

분석 기준 좌표와 점포 좌표 사이 직선거리를 미터 단위로 계산한다. 업종 `c`의 반경 `r` 점포 수는 다음과 같다.

`N(c, r) = 업종 코드가 c이고 기준 좌표에서 거리 ≤ r인 점포 레코드 수`

여기서 `r ∈ {1, 2, 3, 4, 5}km`이며 경계에 정확히 놓인 점포는 포함한다. 누적값은 거리가 늘어도 감소하지 않아야 한다.

두 목록 모두 같은 정렬 함수를 사용한다. 모든 검증된 업종 코드에서 전체 TOP20을 뽑고, 같은 점포 집계에서 `A`로 사전 고정된 코드만 추린 뒤 A TOP10을 뽑는다. 정렬 키는 다음과 같이 오름차순이다.

`N(5km) → N(4km) → N(3km) → N(2km) → N(1km) → 업종 코드`

예를 들어 5km 점포 수가 같은 업종이면 4km 점포 수가 더 적은 업종을 앞에 둔다. 다섯 반경 수까지 모두 같으면 업종 코드 오름차순으로 순서를 고정해 반복 분석의 결과가 같도록 한다.

다섯 반경 count가 모두 같은 업종은 공급 수치상 동률이다. 코드 정렬은 표 순서를 재현하기 위한 장치일 뿐, 동률 업종 사이의 우열을 뜻하지 않는다.

전체 TOP20은 A/B/C 태그와 관계없이 전체 업종을 후보로 둔다. A TOP10은 태그를 확인한 A 코드만 후보로 두며, A/B/C를 유망도 점수로 해석하지 않는다. 전체 TOP20과 A TOP10은 모두 **주변에서 공급이 적게 관측된 순위**다. 수요, 성장성, 경쟁 적정도, 수익성, 창업 적합성을 뜻하지 않는다. 0개와 1개 이상 희소는 실제 count로 구분해 고객이 직접 판단하게 한다.

A 태그는 `[05_ABC_분류_작업표.csv](05_ABC_분류_작업표.csv)`에 기록하고 코드별 분류 근거와 함께 해시 기반 버전으로 고정했다. A는 생활권 일반 소비자 방문형을 뜻하며 구매 빈도만으로 분류하지 않는다. B는 시설·입지 의존형, C는 특수·전문 목적형이다. 분류표 버전과 태깅 기준일을 분석 결과에 기록한다. 새 분류표 변경은 분석 결과를 보기 전에 검토하고 새 버전으로 기록한다. A TOP10은 검증된 A 업종이 10개 미만이면 상품 발행을 보류한다.

## 4. A/B/C 업종 참고 태그

태그는 업종의 일반적인 운영·입지 성격을 간단히 안내한다. 전체 TOP20에서 업종을 제외하거나 점수를 가감하지 않는다. 단, 별도 A TOP10의 후보 범위를 정하기 위해 A 태그를 사용한다. 코드별 태그는 [04_업종 ABC 안내](04_업종_ABC_안내.md) 원칙에 따라 검토·고정한다.

- **A — 생활권 일반 소비자 방문형:** 음식점, 일반 소매, 개인 서비스, 교육 등 생활권에서 일반 소비자가 방문·이용하는 업종의 예. 구매 빈도만으로 태그를 정하지 않는다.
- **B — 시설·입지 의존형:** 자동차·연료, 숙박, 대형 스포츠시설처럼 공간·설비·접근성 등 입지 조건이 중요한 업종의 예.
- **C — 특수·전문 목적형:** 특수 시설, 목적 방문, 산업·전문 서비스 등이 포함될 수 있는 업종의 예.

예외 업종이 있고 하나의 태그로 업종 전체를 설명하기 어렵다. 247개 전체 태그와 경계 29개에 대한 운영자 결정을 분석 결과 확인 전에 기록하고 최종 분류표 버전을 고정했다. 태그는 공급 현황 설명과 A TOP10 모집단에만 사용하며 창업 적합성이나 수익성을 뜻하지 않는다. 고객에게는 최종 창업 판단을 맡긴다.

## 5. 데이터 처리 원칙

- **정상적인 0건:** 해당 업종에 대해 선택한 수집 방식의 완전성 검증이 끝난 경우에만 0건으로 기록한다. 스냅샷 방식은 파일 무결성·파싱·taxonomy 매핑 완료를, API 방식은 정상 응답·예정 페이지·수신 건수 완료를 확인한다.
- **조회 실패·누락:** API 오류, 누락 페이지, 미매핑 코드, 좌표 파싱 실패를 0건으로 바꾸지 않는다. 분석을 중단하거나 결과를 미완료로 표시한다.
- **중복:** 제공기관의 안정적인 점포 ID와 스냅샷 ID를 우선 사용해 중복 페이지 재수집이 count를 늘리지 않도록 한다. 같은 주소·상호만으로 점포를 합치지 않는다.
- **좌표:** 경도·위도 순서와 좌표계를 확인하고, 구면거리 기준으로 반경을 계산한다.
- **자료 시점:** 원자료의 실제 기준일을 표시한다. API 조회시각을 점포 현황의 실시간 확인으로 표현하지 않는다.
- **현재 검증 스냅샷:** 소상공인시장진흥공단 2026-06-30 전국 CSV, 2,772,484개 원자료 행. 원본 ZIP CRC 및 SHA-256 검증, taxonomy 247개 전체 관측, DB 적재 행·공간 인덱스 무결성 검증을 완료했다. 상세 수치는 `data/raw/manifest_20260630.json`과 `data/processed/snapshot_validation_20260630.json`에 기록한다.
- **분류표:** 코드·명칭·유효상태·대/중/소분류를 버전으로 관리한다. 분류표 버전과 분석 방법 버전을 결과에 기록한다.
- **내부 거리구간 수:** 누적 count 차이로 0~1km, 1~2km, 2~3km, 3~4km, 4~5km 신규 점포 수를 계산·저장한다. V1 고객 제공 항목에는 넣지 않는다.

## 6. 고객 고지 문구

> 본 분석의 ‘공백·희소’는 표기된 공공데이터 기준일과 업종분류에 따라 해당 반경에서 관측된 점포 수가 적거나 0건이라는 뜻입니다. 수요가 높거나 수익성이 있다는 뜻이 아니며, 창업 성공을 보장하지 않습니다. 공공데이터는 실시간 현황과 다를 수 있으므로 최종 의사결정 전에 실제 점포 현황을 직접 확인하시기 바랍니다. 본 자료는 창업 검토를 위한 참고자료이며, 최종 판단은 고객의 몫입니다.

## 7. 상품 범위 밖

현재 상품은 업종별 관측 점포 수, 전체 TOP20, A TOP10만 다룬다. 인구·세대·유동인구·매출·임대료·배달 주문·경쟁업체 리뷰·성공 예측·유망업종 추천을 포함하지 않는다. PDF/XLSX 생성과 샘플의 시각 검수는 완료했으며, 실제 주문 주소 결과로 생성·대조하는 운영 리허설이 남아 있다.
