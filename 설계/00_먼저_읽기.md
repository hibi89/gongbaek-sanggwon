# 공백상권 분석 프로젝트 — 먼저 읽기

작성 기준일: 2026-10-01
설계 상태: **SPEC FREEZE** — 구현 중 데이터·운영 사실과 충돌하지 않는 한 상품 사양은 변경하지 않는다.

## 확정한 상품

**공공데이터 기반 247개 업종 공백상권 분석 — 79,000원 단일 상품**

- 고객 입력: 분석 주소 1곳
- 분석 범위: 2026-06-30 공식 전국 CSV에서 확인된 소분류 247개
- 결과 1: 전체 검증 업종 중 공급이 가장 적게 관측된 TOP20
- 결과 2: A 태그(생활·방문형) 업종 중 공급이 가장 적게 관측된 TOP10
- 각 업종의 반경 1km·2km·3km·4km·5km 누적 점포 수 제공
- 전체 TOP20은 A/B/C 태그에 영향받지 않는다. A 태그는 별도의 보조 TOP10을 정할 때만 모집단으로 쓴다.
- B/C 업종도 전체 TOP20 집계에서 제외하지 않는다. A/B/C는 창업 적합성 점수가 아니다.
- 검증된 현행·지원 A 업종이 10개 미만이거나 경계 업종의 운영자 결정이 남아 있으면 상품 전체 발행을 보류한다.
- 수요·매출·수익성·성공 가능성을 추천하거나 보장하지 않는다. 의사결정은 고객의 몫이다.

### TOP20 정렬 규칙

두 목록은 같은 정렬을 쓴다. 5km 점포 수가 적은 업종부터 정렬하고, 동률이면 4km, 3km, 2km, 1km 점포 수 순으로 비교한다. 전부 같으면 업종 코드 오름차순으로 고정한다. 전체 TOP20은 전체 검증 업종, A TOP10은 출시 전에 고정한 A 코드만 후보로 삼는다. 둘 다 **공백 또는 희소하게 관측된 업종 목록**이지 유망업종 추천 순위가 아니다.

## 현재 구현 상태

공식 전국 CSV(`2026-06-30` 기준) 원본을 내려받아 CRC·SHA-256·스키마·좌표·점포 ID·업종코드를 검증했다. 2,772,484개 행에서 소분류 247개가 모두 관측됐고, 미매핑·중복 ID·좌표 오류는 0건이다. 2026-09-30 공공데이터포털 공식 페이지도 현행 파일을 `20260630`으로 표시하고 분기 갱신·다음 등록 예정일 2026-10-31을 안내한다. 원본과 검증 보고서는 `data/raw`, `data/processed`에 보관한다.

247개 전체의 결과를 보기 전 A/B/C 분류를 고정했다. 운영자 검토 결과는 13개 승인·16개 수정이며 최종 분포는 A 122개, B 39개, C 86개다. 최종 taxonomy 버전은 `semas-20260630-taxonomy-v3-abc-6048205a8203`이다. [운영자 검토표](../outputs/01a0ef12-9967-7620-a26b-a78c29e42150/ABC_태그_운영자_최종검토.xlsx)와 05 CSV, 03 JSON이 이 분류를 기록한다. A는 생활권 일반 소비자 방문형으로 구매 빈도만으로 구분하지 않는다. 이 버전으로 SQLite를 재구축·검증해 서비스 DB로 승격했고 분석기 `/health`가 준비 상태를 반환한다.

루트 `배달상권분석.json`은 과거 초안이라 247개 분석에 쓰지 않는다. 새 `배달상권분석_공백상권_V1.json`은 Kakao 주소 변환 뒤 로컬 Python 분석기를 호출한다. 2026-10-01 현재 분석기·workflow·납품물·보관 정리 자동 테스트 53개가 통과했다. 기존 정상 E2E와 공개 주소 5곳의 7개 노드 실행, analyzer 연결 거부(execution 278), publication gate 차단(execution 280)을 확인했다. 현행 taxonomy 전체 SHA-256을 넣어 PDF/XLSX 비식별 샘플을 재생성하고 자동 검사했다. 30일 삭제 절차는 가짜 주문·격리 DB로 끝까지 리허설했으며, 실제 고객 주문과 실제 n8n UI 기록 삭제는 미실행 상태다. live 시험 후 Analysis Input은 placeholder, analyzer URL은 운영 주소로 복원했고 Analyzer test pin이 없는 것을 저장된 n8n DB에서 확인했다.
