## 4. 최종 합격 확인

최종 검토서의 출시 합격 조건을 체크한다. 화면만 예쁘고 exporter가 여전히 2쪽이거나, 판매 문구만 바뀌고 주소가 history에 남는 상태는 완료가 아니다. 기존 자동 테스트 통과와 실제 주소·관심 업종 카드의 읽기 검수를 함께 확인한다.

유료 납품에서 확인할 지표는 주문별 직접 작업시간, 납기 준수, 수정 원인, 고객이 이해한 사실과 다음 확인 대상이다. 리뷰 평점을 조건으로 혜택을 주거나 임의 후기를 만들지 않는다. 공백이 적게 나온 지역도 납품 내용이 약속에 맞으면 정상 결과로 설명한다.

GitHub 업로드와 크몽 게시를 이번 검토에서 수행한 것은 아니다. 원래 폴더의 코드나 상품 문구도 이번에 수정하지 않았다. 다음 담당자가 위 사양대로 수정하고 검증한 뒤 게시한다.
