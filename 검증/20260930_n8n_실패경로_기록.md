# n8n 실패 경로 확인 기록

작성 기준일: 2026-09-30  ·  대상: `공백상권 분석 V1 - 247개 업종`

## 실제 실행 기록 확인

기존 n8n UI 실행기록의 결과 상태와 오류 노드를 확인했다. 아래 주소·좌표 및 인증값은 기록하지 않는다.

| Execution | UI 결과 | 실패 노드 | 확인된 원인 | 처리 |
|---:|---|---|---|---|
| 254, 261 | Error | Validate Analysis Input | 분석 주소가 입력되지 않음 | 주소 입력 필수 검증에서 중단 |
| 260 | Error | Kakao Address | Kakao API 인증 실패 | Kakao credential 수정 후 성공 실행으로 재검증 |
| 263 | Error | Analyze 247 Categories | n8n Header Auth credential의 헤더명이 유효하지 않음 | Analyzer credential을 `Authorization` 헤더로 수정 후 성공 실행으로 재검증 |
| 266, 267 | Error | Validate Address and Coordinates | Kakao 주소 응답에서 유효 좌표를 검증하지 못함. 267은 응답 본문 구조 처리 결함이 함께 확인됨 | 응답 상태와 `body.documents`를 읽도록 validator 수정 후 271·272 정상 실행 확인 |

각 execution은 실제 workflow UI에서 오류 상태와 중단 노드를 확인했다. 오류 난 노드 뒤의 분석·TOP20·A TOP10·publication gate까지 완료된 것으로 처리하지 않았으며 해당 실행으로 납품물을 만들지 않았다. 263의 오류는 analyzer의 정상 401 응답을 확인한 것이 아니라 n8n credential 형식 문제로 HTTP 요청이 정상 구성되지 않은 경우다.

Analyzer 인증 자체도 loopback 서비스에 시험용 잘못된 Bearer 값으로 `POST /analyze` 요청해 확인했다. 실제 응답은 HTTP 401, `{"status":"unauthorized"}`였고 분석은 실행되지 않았다. 시험용 잘못된 값을 사용했으며 운영 토큰은 노출하거나 변경하지 않았다.

동일 endpoint에 정상 로컬 credential과 WGS84 범위를 벗어난 좌표를 보내자 HTTP 400, `{"status":"analysis_failed","publishable":false,"error":"Coordinates are outside WGS84 longitude/latitude bounds"}`를 반환했다. 고객 주소 없이 검증 좌표만 사용했다.

V1 workflow에서 publication gate Code 노드의 실제 JavaScript를 읽어 Node.js 24.21.0에서 실행하는 재현 스크립트 `scripts/verify_publication_gate.cjs`도 추가·실행했다. 정상 fixture 1건은 전달 검토 가능 상태로 통과하고, analyzer HTTP 오류·분석 미완료·publication gate 미통과·247개 범위 불일치·미분류 존재·TOP20 부족·A TOP10 부족 7건은 모두 예외로 거부됐다. 이 검사는 실제 n8n workflow 실행이 아니라, workflow에 저장된 동일한 Code 노드 본문을 mocked `$input`으로 실행한 것이다.

## 현재 성공 확인

재기동 후 execution 272에서 Kakao와 analyzer HTTP 200, 검증된 좌표, 247개 집계, 전체 TOP20 20개, A TOP10 10개, `publication_gate=passed`를 확인했다. 상세 수치와 PDF/XLSX 생성 검증은 [E2E 실행 272](20260930_n8n_e2e_실행272_재기동확인.md)에 기록했다.

## 남은 검증 경계

- 크몽 실제 주문 접수·고객 파일 전달은 아직 리허설하지 않았다.
- 30일 삭제 절차는 가짜 주문·격리 DB/폴더로 끝까지 리허설했지만, 실제 n8n UI에서 execution 삭제 후 목록/DB에서 제거되는지 확인하는 별도 검증은 하지 않았다.

이 문서는 판매 전 점검에 필요한 실제 실패 근거를 정리한 것이며, 실제 주문 운영과 보관 만료 삭제까지 완료됐다는 뜻은 아니다.
