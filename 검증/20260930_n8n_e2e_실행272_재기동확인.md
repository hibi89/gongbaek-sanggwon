- `python -m unittest discover -s tests -v`: 초기 재기동 확인 시 42개 통과. 이후 만료정리 테스트 10개를 추가했으며 최신 suite는 52개 통과.
- 검증 실행 로그: `20260930_n8n_retention_start_stdout.log` (시작 설정·ready·버전 기록), `20260930_n8n_retention_start_stderr.log`.
- n8n 프로세스 내부 환경변수 직접 read-back은 OS 권한 제약으로 **미확인**이다. 로그상 시작 설정은 pruning `true`, 최대 보관 `900`시간, count 제한 `0`이다.
- 시작 로그에 n8n 내부 Python task runner용 가상환경이 없어 runner 시작에 실패했다는 경고가 있다. 현재 분석 workflow는 Python task runner에 의존하지 않고 별도 analyzer 서비스에 요청하므로 이번 E2E는 통과했다. n8n 내부 Python Code 노드를 추가할 경우에는 별도로 runner를 구성해야 한다.
- DB ping timeout 1회 뒤 연결 복구 메시지가 기록됐고, n8n health 및 실행은 정상 완료했다.
