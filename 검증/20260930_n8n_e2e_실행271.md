## E2E 과정에서 수정한 좌표 매핑 오류

n8n execution 267에서 Kakao 응답은 HTTP 200과 주소 결과 1건이었지만 좌표 검증 노드가 실패해 analyzer로 진행하지 못했다. execution에 저장된 당시 workflow definition을 비교해 원인을 확인했다. HTTP Request의 `fullResponse=true`로 응답이 `body` 아래에 있었는데 당시 좌표 검증 코드는 최상위 `documents`만 읽었고 Kakao HTTP 상태도 전달하지 않았다. 현재 validator는 `body.documents`와 응답 상태를 함께 처리하며, 이 동작은 자동 workflow 계약 테스트에 추가했다. 이후 전체 경로 실행 271에서 정상 통과했다.
