- 고객 모드 임시 출력은 `tmp/artifact-work` 아래에 만들었다가 검증 뒤 삭제했다. 확인한 모든 고객 모드 검수 폴더는 삭제 후 실제로 존재하지 않는 것을 확인했다.
- `LOCALAPPDATA`를 프로젝트 내부 격리 폴더로 지정해 기본 저장 규칙 그대로 PDF·XLSX·manifest 생성 및 존재·크기·gate·HTTP 상태를 확인한 뒤 폴더를 삭제했다.
- 후속 실행 272에서 기본 출력 옵션을 사용해 사용자의 실제 `%LOCALAPPDATA%\GapAnalysis\deliveries\GAP-272`에 PDF/XLSX/manifest를 생성했다. 파일 크기·manifest 내용·파일 ID를 대조하고, 확인 뒤 테스트 주문 폴더를 삭제해 부재를 확인했다.
- 운영자 납품 파일 생성은 n8n 실행 뒤 실행하는 CLI 단계다. 현재 workflow 안에서 PDF/XLSX를 자동 생성하지 않는다.
