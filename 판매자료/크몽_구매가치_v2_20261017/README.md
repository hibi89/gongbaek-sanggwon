# 공백상권 크몽 구매가치 개선 v2 (2026-10-17)

**대상:** 기존 승인 대기 상품 「공백상권 분석 247개 업종 공급현황」, 사용자 보고 기준 **49,000원**. 신규 상품이나 가격 인상안을 등록하지 않는다.

## 구매 가치 핵심
1. **업종 후보 발견:** 카페·음식점 등 익숙한 업종을 넘어 247개 업종의 공급 현황을 살펴볼 수 있다.
2. **조사 시간 절약:** 무료 지도에서 업종을 하나씩 찾고 정리하는 일 대신 같은 기준으로 집계한 자료를 받는다.
3. **근거 있는 비교:** 주소 한 곳, 반경 1/2/3/4/5km의 업종별 누적 점포 수, 전체 희소 TOP20, A 생활·방문형 TOP10을 PDF/XLSX로 확인한다.

실제 데이터는 **2026-06-30 기준 전국 상가 2,772,484건 / 247 업종 / A 122개**. PDF 예시 2페이지, XLSX는 요약·전체 247개 시트다. 반경은 **직선거리**이고 자료는 실시간이 아니다.

**중요:** '공급이 적다'는 '수요가 충분하다' 또는 '수익성이 좋다'가 아니다. 실매출·유동인구·임대료·구매확률·성공 가능성·유망 창업업종 추천은 제공하지 않는다.
