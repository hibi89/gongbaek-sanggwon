# 크몽 등록용 상품 설명

> 내부 상태: **상품 문구 완성 · 크몽 미등록**. 정상 n8n E2E와 PDF/XLSX 파일 생성이 검증됐다. 입력 누락·Kakao 인증·analyzer credential·좌표검증 실패와 analyzer 연결 거부·publication gate 차단의 live 중단을 확인했다. 실제 크몽 주문부터 전달까지의 리허설과 n8n UI 실행기록 삭제 확인은 남아 있다. 아래 30일 보관은 자동삭제가 아니라 전달일 기준 운영 절차다.

## 상품명

**공공데이터 247개 업종 공백상권 분석 | 주소 주변 희소 업종 TOP20**

## 가격

**79,000원 · 주소 1곳 분석**

## 한 줄 소개

분석 주소 주변 1~5km의 점포 현황을 공공데이터 247개 세부업종으로 비교하고, 전체 희소 업종 TOP20과 생활·방문형(A) 업종 TOP10을 PDF와 XLSX로 정리해드립니다.

## 상품 안내

창업을 검토 중인 주소 주변에 어떤 업종이 있고, 어떤 업종의 점포가 상대적으로 적게 관측되는지 확인해보세요.

고객님이 보내주신 주소 한 곳을 기준으로 좌표를 확인한 뒤, 소상공인시장진흥공단 상가(상권)정보의 검증된 세부업종 247개를 집계합니다. 반경 1km·2km·3km·4km·5km의 **누적 점포 수**를 비교해 공급 현황을 정리합니다.

## 제공 결과

- 분석 주소 1곳 기준, 반경 1km·2km·3km·4km·5km 점포 수
- 247개 전체 업종 중 5km 점포 수가 적은 순으로 정렬한 희소 업종 TOP20
- 사전에 확정한 생활·방문형(A) 업종만 대상으로 한 희소 TOP10
- 두 목록의 업종 코드와 각 반경 누적 점포 수
- 분석 기준 주소, 자료 기준일, 분석 기준 안내
- **PDF 요약본 + 247개 전체 업종 XLSX 상세표**

전체 TOP20은 247개 업종 전체에서 산출합니다. A형 TOP10은 A로 고정 분류된 업종만 별도 모집단으로 산출합니다. 두 결과 모두 창업 추천 순위가 아니라 관측된 점포 수에 따른 공급 현황입니다.

## 분석 기준

- 반경은 주소에서 변환한 좌표를 중심으로 계산합니다.
- 점포와 기준점 사이의 직선거리로 집계하며, 각 반경 경계에 있는 점포도 포함합니다.
- 희소도는 5km 점포 수를 우선 비교하고, 동률이면 4km·3km·2km·1km 순으로 비교합니다.
- 실제 사용한 공공데이터의 기준일을 결과물에 표시합니다.

## 주문 시 필요한 정보

1. 분석할 도로명 또는 지번 주소 한 곳
2. 주소와 분석 기준점이 다를 경우 건물명·출입구 등 위치 설명
3. 결과물에 표시할 상호 또는 프로젝트명(선택)

주소 검색 결과가 여러 곳이거나 기준점을 확인하기 어려우면 임의로 처리하지 않고 먼저 확인을 요청드립니다.

## 작업 기간과 수정

- 표준 납기: 주소와 기준점을 확인한 뒤 **영업일 2일 이내**
- 분석을 시작하기 전까지 주소 수정이 가능합니다.
- 분석을 시작한 뒤 수정이나 재작업이 필요한 경우에는 진행 상태와 주문 조건에 따라 안내드립니다.

## 데이터와 개인정보 안내

주소는 Kakao Local API로 좌표를 확인하는 데 사용합니다. 점포 분석은 검증된 전국 공공데이터 스냅샷을 사용합니다. 분석 주소, n8n 실행기록 및 내부 결과파일 사본은 결과 전달 후 30일간 보관한 뒤 삭제합니다. 고객님이 내려받아 보관하는 파일에는 이 내부 삭제가 적용되지 않습니다.

## 꼭 확인해 주세요

- ‘공백·희소’는 표기된 공공데이터 기준일에 해당 반경 안에서 점포가 0개 또는 상대적으로 적게 관측됐다는 뜻입니다.
- 공백이 수요, 매출, 수익성 또는 창업 성공을 보장하지 않습니다. 수요가 적어서 점포가 없을 수도 있습니다.
- 공공데이터는 실시간 현황과 다를 수 있습니다. 최종 의사결정 전 실제 점포와 영업 여부를 확인해 주세요.
- 이 상품에는 매출·유동인구·임대료·배달 주문량 분석이나 유망 업종 추천이 포함되지 않습니다.
- A는 생활권 일반 소비자 방문형, B는 시설·입지 의존형, C는 특수·전문 목적형을 뜻하는 설명 태그입니다. 공공데이터의 공식 분류나 창업 적합도 평가는 아닙니다.

## 주문 접수 안내 문구

주소와 기준점을 확인했습니다. 지금부터 분석을 시작하며, PDF 요약본과 247개 전체 업종 XLSX를 주소 확인 후 영업일 2일 이내 전달드리겠습니다. 분석 시작 전 주소 수정이 필요하시면 바로 말씀해 주세요.

## 결과 전달 안내 문구

요청하신 공백상권 분석 결과를 전달드립니다. 첨부된 PDF는 전체 희소 업종 TOP20과 A형 희소 TOP10 요약본이며, XLSX에는 247개 업종의 1~5km 누적 점포 수를 담았습니다.

‘공백·희소’는 표기된 공공데이터 기준일에 관측된 점포 수를 뜻하며, 수요나 수익성을 의미하지 않습니다. 공공데이터는 실제 현황과 차이가 있을 수 있으니 창업 판단 전에 현장 점포와 영업 여부를 확인해 주세요. 분석 주소와 실행기록, 내부 결과파일 사본은 결과 전달 후 30일간 보관한 뒤 삭제합니다.
