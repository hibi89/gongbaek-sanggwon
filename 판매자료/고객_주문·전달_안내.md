# 고객 주문·결과 전달 안내 초안

> 내부 운영 초안입니다. 분석기와 n8n 정상 E2E는 확인했습니다. 고객 납품물은 PDF 요약본과 XLSX 상세표, 표준 납기는 영업일 2일입니다. 30일 삭제 절차와 주문 처리 리허설을 검증한 뒤 고객에게 사용합니다.

## 주문할 때 받을 정보

- 분석 주소 1곳: 도로명 또는 지번 주소
- 지도상 기준점이 주소와 다르면 건물명·출입구 등 기준점 설명
- 결과물에 표시할 이름(선택)

고객에게 주소 하나만 요청하고, 결과 표시에 필요하지 않은 개인정보는 받지 않는다.

주소 검색 결과가 여러 곳으로 나뉘거나 분석 기준점을 확인할 수 없으면 임의 좌표로 처리하지 않고 고객에게 확인한다.

입력한 주소는 기준 좌표 변환을 위해 Kakao Local API에 전달된다.

> 당사가 보유하는 분석 주소, n8n 실행기록 및 내부 납품물 사본은 결과 전달 후 30일 동안 보관한 뒤 삭제합니다. 주소 수정은 분석을 시작하기 전까지 요청할 수 있습니다.

## 게시 전 운영정책 입력란

- 고객 납품 파일: **PDF 요약본 + 247개 전체 업종 XLSX 상세표**
- 표준 납기: **주소 확인 후 영업일 2일 이내**
- 분석 시작 전 주소 수정: **가능**
- 분석 완료 후 수정·환불: **[크몽 판매 조건에 맞춘 기준]**
- 주소·실행기록·내부 납품물 사본의 보관·삭제: **결과 전달 후 30일 보관 후 삭제. 분석 실행 ID와 전달일을 삭제 대장에 기록하고 기한이 되면 n8n 기록과 내부 사본을 삭제·확인한다. 고객이 내려받은 사본에는 이 내부 삭제가 적용되지 않는다.**

## 내부 처리 흐름

1. 주문 주소를 좌표로 변환하고 정규화 주소를 확인한다.
2. 검증 완료된 자료 기준일과 247개 업종 매핑을 확인한다.
3. 기준점부터 5km 안의 점포 후보를 검색하고 정확한 거리로 1~5km 누적 수를 계산한다.
4. 전체 업종 TOP20과 승인된 A 업종 TOP10을 같은 정렬 기준으로 계산한다.
5. 0건·누락·오류를 확인한다. 자료 처리 실패를 0건으로 바꾸지 않는다.
6. PDF 요약본과 247개 상세 XLSX의 수치·기준일·분류표 버전을 대조한다.
7. 결과 전달일과 n8n 실행 ID를 삭제 대장에 기록하고, 전달 후 30일이 지나면 실행기록·내부 PDF/XLSX·주소 포함 임시 입력을 삭제한 뒤 실제 부재를 확인한다.

## 고객에게 결과를 전달할 때

> 본 결과의 ‘공백·희소’는 표기된 공공데이터 기준일에 해당 반경에서 관측된 점포 수를 뜻합니다. 수요·수익성·창업 성공 가능성을 의미하지 않습니다. 공공데이터는 실시간 현황과 다를 수 있으므로 실제 점포 현황을 확인하고 창업 의사결정을 내려주시기 바랍니다.

TOP20은 247개 업종 전체에서 5km 점포 수가 적은 순으로 뽑은 공급 현황 목록입니다. A TOP10은 결과를 보기 전에 고정한 생활·방문형 업종만 별도 모집단으로 삼습니다. 두 목록 모두 창업 추천 순위가 아닙니다.

오류·미완료 상태라면 완성된 결과물인 것처럼 전달하지 않는다. 주소 확인, 스냅샷 재검증 등 재작업 사유를 먼저 안내한다.

## 내부 검수 체크

- 분석 기준 주소가 고객 요청과 일치하는가?
- 원자료 기준일과 분류표 버전이 기록됐는가?
- 대상 업종 247개가 모두 정상 집계됐는가?
- 반경 누적 수가 1km ≤ 2km ≤ 3km ≤ 4km ≤ 5km인가?
- TOP20과 A TOP10의 정렬이 같은 기준을 따르는가?
- A/B/C 분류표가 승인된 버전인가?
- 0건을 데이터 실패·미매핑과 구분했는가?
- 출처, 기준일, 참고자료 고지를 포함했는가?
- 고객에게 Kakao Local API 주소 전달 사실과 주소·실행기록 보관 안내를 제공했는가?
- 납품 형식과 약속한 납기가 크몽 판매 페이지와 일치하는가?

## 삭제 대장 작성 규칙

`운영/30일_보관_삭제_대장.csv`에는 분석번호, n8n 실행 ID, 고객 전달일, 삭제 예정일, 삭제 확인일, 처리상태만 기록한다. 고객 이름, 주소, 전화번호는 적지 않는다. 삭제 예정일에 n8n 실행기록과 내부 결과 파일을 삭제하고 실제 부재를 확인한 뒤 삭제 확인일과 처리상태를 기록한다. 이 절차와 현재 n8n pruning 설정을 검증한 뒤에만 외부 고객에게 30일 보관 문구를 적용한다.
