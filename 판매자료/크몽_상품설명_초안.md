## 제목

**공공데이터 247개 업종 공백상권 분석 | 주소 주변 희소 업종 TOP20**

## 가격

**79,000원 · 주소 1곳 분석**

## 한 줄 소개

예정 입지 주변의 점포 현황을 공공데이터의 247개 세부업종으로 전수 비교해, 1~5km 누적 점포 수가 적게 관측된 업종 TOP20과 생활·방문형(A) 업종 TOP10을 정리해드립니다.

## 상품 설명

창업을 검토하는 주소 주변에 어떤 업종이 있고, 어떤 업종이 상대적으로 적게 관측되는지 확인하고 싶으신가요?

분석 주소 한 곳을 기준으로 소상공인시장진흥공단 상가(상권)정보에서 확인되는 247개 세부업종을 전수 집계합니다. 반경 1km·2km·3km·4km·5km의 **누적 점포 수**를 비교하고, 5km 점포 수가 적은 순으로 전체 업종 TOP20을 제공합니다. 생활·방문형으로 사전 분류해 고정한 A 업종 TOP10도 별도로 보여드립니다.

이 자료는 창업 후보를 직접 검토할 때 주변 공급 현황을 참고할 수 있도록 돕습니다. 특정 업종을 추천하거나 매출·수요·수익성·성공 가능성을 예측하지 않습니다.

## 제공 범위

- 분석 주소 1곳
- 분석 기준 주소 및 공공데이터 기준일 표시
- 공식 스냅샷에서 확인된 세부업종 247개 전수 집계
- 전체 공백·희소 업종 TOP20
- 생활·방문형(A) 공백·희소 업종 TOP10
- 각 업종별 1km / 2km / 3km / 4km / 5km 누적 점포 수
- 업종 코드와 A/B/C 참고 태그
- PDF 요약본과 247개 전체 업종 상세 XLSX
- 정상 조회에서 0개인 경우와 조회 실패를 구분

247개 전체를 분석 모집단으로 사용합니다. PDF에는 핵심 TOP20과 A TOP10을 담고, XLSX에는 247개 전체 업종의 코드·분류 태그·1~5km 누적 점포 수와 희소 순위를 담습니다.

## 분석 기준

- 데이터 출처: [소상공인시장진흥공단 상가(상권)정보](https://www.data.go.kr/data/15083033/fileData.do)
- 분석 범위: 입력 주소의 좌표를 중심으로 반경 5km
- 거리 기준: 점포 좌표와 분석점 사이 직선거리, 반경 경계 포함
- 희소 정렬: 5km 점포 수 → 4km → 3km → 2km → 1km 순으로 비교. 모두 같으면 업종 코드 순으로 표시
- 데이터 기준일: 결과물에 실제 사용한 스냅샷 기준일을 기재

## 주문 시 전달해 주세요

1. 분석할 도로명 또는 지번 주소 한 곳
2. 주소 기준점을 별도로 지정해야 하는 경우 건물명·출입구 등 위치 설명
3. 결과물 표기에 필요한 상호 또는 프로젝트명(선택)

## 납기 및 주소 수정

- 표준 납기: 주소 확인 후 영업일 2일 이내
- 주소 수정: 분석을 시작하기 전까지 요청 가능
- 분석을 시작한 뒤의 수정·재작업·환불은 크몽 주문 조건과 진행 상태에 따라 안내합니다.

## 주소 처리 안내

입력한 주소는 분석 기준 좌표를 확인하기 위해 Kakao Local API에 전달됩니다. 공공데이터 점포 분석은 좌표 변환 후 로컬 분석기에서 수행합니다.

당사가 보유하는 분석 주소, n8n 실행기록 및 내부 결과파일 사본은 결과 전달 후 30일간 보관한 뒤 삭제합니다. 주소 수정은 분석 시작 전까지 요청할 수 있습니다.

## 반드시 확인해 주세요

- ‘공백·희소’는 해당 기준일 공공데이터에서 관측된 점포 수가 0개 또는 적다는 뜻입니다. 수요가 높거나 수익성이 있다는 의미가 아닙니다.
- 공공데이터는 실시간 점포 현황과 다를 수 있습니다. 실제 점포·영업 여부를 직접 확인한 뒤 의사결정해 주세요.
- TOP20은 5km 점포 수를 우선으로 정렬한 공급 현황 순위이며 유망 업종 추천 순위가 아닙니다. A TOP10도 고정된 A 업종 모집단에서 점포 수가 적게 관측된 목록입니다.
- 좌표 변환이 불명확하거나 데이터 검증이 완료되지 않으면 0개로 표시하지 않고 확인 또는 재작업 대상으로 안내합니다.
- 이 서비스에는 매출·유동인구·임대료·배달 주문량 분석과 창업 성공 예측이 포함되지 않습니다.
- A/B/C 태그는 공식 업종 분류나 창업 적합도 평가가 아닌 설명용 분류입니다.
