1. 먼저 GitHub 최신 `HANDOFF.md`, `STATUS.md`, 이 폴더 README를 확인한다. 최종 ZIP `공백상권_크몽_최종등록패키지_20261017.zip`의 SHA-256 `2f6c0097c91b4f03421e5facb803b2053f81ed81b10916d6c44fa6fb033d8dcb`와 내부 15개 파일을 검증한다. **ZIP은 현재 GitHub에서 자동 pull되지 않는다**.

4. ZIP의 고객용 상품설명 `01_크몽_등록용_상품설명.txt` 사용, FAQ는 `02_구매자_FAQ.md`. 최종 문구 **2026-06-30 데이터 + 2026-10-31 차기 등록 예정 + 새 자료 검증 후 갱신**을 빠뜨리지 않는다. '실시간', '유망 창업 추천', '매출 예측' 금지.
5. 대표 1장, 상세 이미지 6장을 ZIP 순서대로 적용. 모바일·데스크톱에서 텍스트 잘림·흐릿함을 확인. 비식별 PDF·XLSX는 플랫폼 지원/규격·개인정보 확인 후 미리보기로만.

8. 종료 후 적용 URL·상품 ID·상태·가격·이미지·본문·공공데이터 안내 문구·재심사 여부를 보고하고 `STATUS.md`/`HANDOFF.md` 갱신.
